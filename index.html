    Edit without leaving the screen

    • Shortcuts: B or double left-click over the image enters Add Box; V returns to editing; Esc cancels. Double right-click the same visible box to delete it; Ctrl+Z restores it. A single right-click selects the box. Right-click menus are disabled only over the image. Middle-drag still pans. Numbers change the selected box’s class, or choose the next box’s class in Add Box mode: 0 valve, 1 flange, 2 elbow, 3 pipe, 4 tank, 5 pump, 6 strainer, 7 tee, 8 reducer. Shortcuts pause while typing in fields.
    • Copy / paste: Press left and right mouse buttons together once on a box to copy. At the destination, press and release both buttons together twice within 650 ms to paste. Keep the pointer still between the two presses. Copying is immediate. A second combined press within 650 ms pastes the box that was copied before the first press, so the destination cannot replace your source. Ctrl+C copies the selected box; Ctrl+V pastes at the last pointer position over the image. Mouse-only alternative: select a box, click Copy box, click Paste, then left-click the image to place the preview. Right-click or Esc cancels placement. The Paste button displays the copied class and ID. The combined-button gesture works in Edit, Add Box and Pan modes. A pasted box retains class, angle, dimensions and uncertainty, receives a new ID, and marks the destination view Not reviewed. Ctrl+Z undoes a paste. The copied box remains available while switching views in this panorama.
    • Find uncertainty: The top card counts all active uncertain boxes across the panorama, including hidden classes. Click to visit an affected view and zoom to a flagged box; click again for the next affected view, wrapping to the first. Use “Next uncertain box” to cycle boxes within the current view. Gold labels and a ring around tiny boxes make flags easier to spot. Resolving, deleting, importing or undoing edits updates the counts immediately. Navigation never changes review approval.
    • Eraser (E or wheel-button click): Click the mouse wheel once to turn Eraser on; click again to return to Edit boxes. Middle-button dragging still pans. Hold the left mouse button and brush across any box edge to erase it immediately. The small red circle shows the touch radius. Fast strokes also catch edges between pointer positions. Class filters apply; hidden boxes remain. One stroke is one undo step (Ctrl+Z). Esc or right-click cancels the current stroke. Space or middle-drag pans.
    • Zoom: mouse wheel over the image, + / −, or “Zoom to box”. “Fit” resets the view.
    • Pan: drag empty space, use Pan mode, or hold Space and drag anywhere. Shift+wheel pans sideways.
    • Move: in Edit boxes mode, drag a box. Overlapping boxes can be selected from the list.
    • Resize: drag one of the four round corner handles. The rectangle keeps its angle.
    • Rotate: drag the handle connected above the selected rectangle, or enter an angle.
    • Missing object: choose + Box, drag its rectangle, then choose its class.
    • Correct / remove: use a class dropdown or Delete box. Undo / Redo are available. Arrow keys nudge a selected box; Shift moves 10 pixels.
    • Send back: Download edits saves exact image coordinates and classes. No new image is needed. Import JSON restores an exported session on another browser.
